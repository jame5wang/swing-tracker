# 波段追蹤台（自動盤後版）

每個交易日自動抓取證交所「上市股票」盤後收盤價，追蹤你已篩選過基本面的股票的買賣價位。

## 目前功能
- 每個交易日台北時間下午 3:00，自動抓取所有「上市」＋「上櫃」股票收盤價
- 開網站時自動比對你追蹤的股票代號，帶入當天收盤價
- 手動設定買進價 / 停利價 / 停損價 / 技術支撐壓力，自動判斷目前屬於哪個區間
- 手動記錄新聞、法人報告、法說會、營收重點

⚠️ 上櫃資料來源（TPEx OpenAPI）有防機器人機制，我無法在製作當下即時測試確認欄位名稱是否 100% 正確。第一次執行排程後，請照下方「檢查上櫃資料有沒有抓到」確認一次。

## 部署步驟（約 5 分鐘，全部免費）

1. **建立 GitHub 帳號**（如果還沒有）：https://github.com/join

2. **建立新的 Repository**
   - 右上角 `+` → `New repository`
   - 名稱隨意，例如 `swing-tracker`
   - 設為 **Public**（GitHub Pages 免費版需要 Public）
   - 建立完成

3. **把這個資料夾裡的所有檔案上傳上去**
   - 在剛建立的 repo 頁面，點 `Add file` → `Upload files`
   - 把這個資料夾裡「所有檔案和資料夾」（包含 `.github` 隱藏資料夾）拖進去
   - 如果網頁介面看不到 `.github` 資料夾（有些瀏覽器會忽略隱藏資料夾），改用下方「進階：用 Git 上傳」的方式

4. **開啟 GitHub Pages**
   - 到 repo 的 `Settings` → 左側選單 `Pages`
   - Source 選擇 `Deploy from a branch`，Branch 選 `main`，資料夾選 `/ (root)`
   - 儲存後，等 1-2 分鐘，頁面上方會出現網址，長得像：
     `https://你的帳號.github.io/swing-tracker/`
   - 這就是你的網站網址，之後可以加到書籤或手機主畫面

5. **確認自動排程有打開**
   - 到 repo 的 `Actions` 分頁，應該會看到 `更新台股盤後收盤價` 這個 workflow
   - 如果想馬上測試一次，不用等到下午 3 點：點進去該 workflow → 右上角 `Run workflow` 手動觸發一次
   - 執行成功後，`data/prices.json` 會被自動更新並提交

## 進階：用 Git 上傳（如果網頁上傳看不到 .github 資料夾）

```bash
cd 這個資料夾的路徑
git init
git add -A
git commit -m "初始版本"
git branch -M main
git remote add origin https://github.com/你的帳號/swing-tracker.git
git push -u origin main
```

## 之後怎麼用
- 每天收盤後，網站打開就會自動帶入當天收盤價（第一次要等排程跑過一次，或手動觸發 Run workflow）
- 你自己輸入的買進價/停利價/停損價/筆記，存在瀏覽器本機，不會被自動更新覆蓋
- 想追蹤新股票：直接在網站上「新增追蹤」，輸入代號即可，收盤價會自動比對帶入

## 檢查上櫃資料有沒有抓到
1. 手動觸發一次排程（`Actions` → `更新台股盤後收盤價` → `Run workflow`）
2. 點進這次執行紀錄，展開 `抓取櫃買中心盤後資料（上櫃）` 這個步驟
3. 看印出來的「原始資料範例」和最後「寫入 N 檔股票資料」
   - 如果 N 是 0 或報錯：代表 TPEx 的欄位名稱跟腳本猜的不一樣，把這段 log 貼回來這個對話，我幫你依實際欄位調整 `scripts/fetch_prices_otc.py`
   - 如果 N 有幾百筆以上：代表成功了，之後就會每天自動更新

## 已知限制
- 興櫃股票不在這個範圍內，不會自動更新
- 若 TWSE 或 TPEx 之後改版 API，抓取可能會失效，屆時排程會執行失敗（在 `Actions` 分頁會看到紅色 X），回來這個對話跟我說，我可以幫你更新腳本
